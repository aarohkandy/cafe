### A-1. A golden path under a directory that cannot be searched raises PermissionError out of `golden_refusal`, `update_command` and `check_golden`, not the refusal row round 13 built; for a plain check it is raised after the first quick run
severity: minor
lane: robustness
where: cafe/pm/acceptance.py:388 (`where.exists()`), :390 and :394 (`golden.exists()`), :443; cafe/pm/acceptance.py:428 (`check_golden` calls `update_command` on every check, update or not), :585-586 (`check_golden` right after `fresh("quick")`); DECISIONS 709, 743, 757
reproduction: on orca, `python rev14a_probe4.py` (scratch, removed): `d/sub` made with mode 0, `g = d/'sub'/'g.json'`; `acceptance.golden_refusal(g, 'm')`, `golden_refusal(g, 'm', 'm')`, `update_command(g, 'missions/x.yaml', 0, 'm', d/'out')` and `check_golden(<run dict>, g, 'missions/x.yaml', False)` all raise `PermissionError: [Errno 13] Permission denied: '.../sub/g.json'`. Python 3.12's `Path.exists()` ignores only ENOENT, ENOTDIR, EBADF and ELOOP, so EACCES (a `--golden` below another user's 0700 directory, or `/root/...`) escapes. By reading `__main__.main` (`_names_a_path_given` finds `--golden` among the typed paths) the CLI turns it into `error: <path>: Permission denied`, exit 2, not a traceback and not the "name another file with `--golden`" advice; for `--update-golden` that is at the start (`run()` line ~560), for a plain `acceptance` it is after the first quick run (5 to 20 minutes), before the other runs and before `acceptance.json` is written (I did not run `acceptance`). `tests/test_acceptance.py:1448` tests the "cannot be written" branch by monkeypatching `os.access`, never with a real unsearchable directory; the mutant `os.access(where, os.W_OK | os.X_OK)` to `os.W_OK` also survives (see A-4).
why it matters: DECISIONS 709/743/757 and RUNBOOK 7 say a golden path no flag can mend, "a directory this user cannot write to", is refused before any run with a message that names the way out; the neighbouring case (cannot search) is a bare errno line and, for the plain check, costs the first run.
