Robots

A robot is characterized once: its drag (CFD), added mass (BEM) and structure (FEA) are computed. After that any mission can use it.

Pick a robot to see how it was characterized, or add your own.

Autopilot

Fly a mission with the software that will really steer the robots: ArduPilot firmware, or your own code. Same physics, same weather.

ArduPilot firmware

ArduCopter flies quads, ArduRover boats and ArduSub thruster-driven subs. Gliders and finned torpedoes have no ArduPilot firmware, so they keep the built-in autopilot. QGroundControl can watch on TCP 5762 (+10 for each extra robot).

Run a mission first: finished missions show up here.

Your own code

Step the simulation from Python and send each robot a target. Your code reads every robot's true position, heading, speed and battery at each step: sensor noise and dropouts are not simulated.
