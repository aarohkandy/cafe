### D-1. A YAML integer of more than 4,300 digits, and a YAML mapping key that is a list, escape `config._yaml` as a bare ValueError / TypeError (traceback, not `error:` exit 2)
severity: minor
lane: robustness
where: cafe/pm/config.py:149-162 (`_yaml`: the `try` catches ConfigError, YAMLError, UnicodeDecodeError, OSError, RecursionError only), config.py:40-50 (`_Loader.construct_mapping`: `seen.add(key)` after a guard that skips only unhashable keys from the membership test), cafe/pm/ledger.py:281 (`values_sha256` catches ConfigError and TypeError only)

why it matters: RUNBOOK 100 says a number too large for a float "in ANY YAML file the code reads" is refused by the one reader and that `hangar --platform` of such a file prints `error:` and exits 2.
