## Security findings on `cafe/atomic.py` (an automated review flagged both)

Code. `atomic.write_text(p, text, follow_symlinks=False)`.
1. The temporary is made with `os.open(tmp, O_WRONLY | O_CREAT | O_EXCL, mode)`, never by `Path.write_text` alone. When the target exists the creation mode is `0o600`, the text is written, and `os.fchmod(fd, <the target's mode>)` sets the mode the file always had before `os.replace`. When the target is new the creation mode is `0o666`, so the kernel applies the umask and the temporary has, from its first byte, the mode the final file gets (`0o666 & ~umask`, as today). This differs from the task's wording ("0o600, then set the mode to `0o666 & ~umask`") in one point only: it never reads the umask. `os.umask` can only be read by setting it, which is process-wide and races with every other thread that creates a file (the app writes job files from threads); the result is the same final mode, and at no moment is the temporary readable more widely than the file it becomes. The temporary is removed if anything after its creation fails; `FileExistsError` from `O_EXCL` is raised before the `try`, so a name that is somebody else's is never unlinked.
2. A symbolic link at `p` is refused: `OSError(ELOOP, "refusing to write through a symbolic link", p)`, before anything is created (a dangling link too). `follow_symlinks=True` takes `os.path.realpath(p)` first, as before. `cafe.pm.config.write_text` passes True, and `config.write_json`, which calls it, follows too. Every caller of `config.write_text` and `write_json` (receipts, audit, acceptance golden, ledgers, report, credibility, tao/surface/hycom/orca manifests, `pipeline` copies of the mission) therefore behaves as rows 706, 739 and 779 say. The default (refuse) is what `app.py`, `worker.py`, `cafe/emulator.py`, `hangar.py`, `cfd.py` and `bench/throughput.py` get through `atomic.write_json`, none edited. `atomic.write_json` has no `follow_symlinks` argument; nothing needs one.

## M-3: an RF link takes the worse margin of its two ends' Hs

Which end is worse, from the formula (written into `_link_hs`'s docstring): the field of the two-ray link is `|1 - r exp(j th)|` with `r = |rho|` (`ament_rho` times the divergence factor) falling as Hs rises and `th` the phase of the path difference; its square is `1 + r^2 - 2 r cos(th)` and its derivative in r is `2 (r - cos(th))`. Where `cos(th) > r` (the nulls and their neighbourhood) the calmer end, the one with the larger r, has the smaller field and is the worse one; where `cos(th) < r` (the peaks, and wherever the reflection is weaker than the direct ray's projection) the rougher end is. No single Hs is the conservative one, and the larger one, which row 651 took, is optimistic at the nulls, by up to 20 dB (the reviewer's and the verifier's sweeps). So the margin is the worse of the two margins, sample by sample.

Code. `stage1._link_hs` returns the two ends' Hs arrays (each filled on its own, `hs_filled` as before); `evaluate_link` computes `comms.rf_margin` for each and takes `np.minimum`. Symmetric in the two namings (R12 M-11 holds: the margins differ by float dust only, `allclose(atol=1e-9)`). The acoustic branch (`np.fmax` of the two winds: the noisier is the worse) is right and unchanged. The in-sortie hook `_uas_links` unchanged. Hs at the two ends is still only a proxy for Hs at the specular point.

DECISIONS row A4 (new; amends 651 and its CHANGELOG line at CHANGELOG.md:692; batch D settles 651's text, which waited on this): "An RF link is evaluated, at each moment, at the worse of the two margins `comms.rf_margin` gives for the significant wave heights of its two ends (`stage1._link_hs` returns one Hs array per end, each filled on its own; `evaluate_link` takes `np.minimum` of the two margins), so the margin does not depend on which end the mission names first, and it is not read off the larger Hs, which row 651 called the conservative one: the field is `|1 - r e^(j th)|` with r (the reflection coefficient, Ament's roughness times divergence) falling as Hs rises, its square changes with r by `2 (r - cos th)`, so a rougher sea fills the interference nulls and raises the minimum margin (by up to 20 dB at ht 15 m, hr 60 m, Hs 0 against 3 m) while lowering the peaks: the worse end depends on the phase at each sample.
